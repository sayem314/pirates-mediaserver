# Prowlarr
======

About
-----

Prowlarr is an indexer manager/proxy built on the common *arr stack. It
integrates natively with Sonarr and Radarr (indexers sync automatically) and
falls back to Torznab and Newznab proxies for anything else. It is the
actively developed successor to Jackett and the default indexer choice of
pirates-mediaserver.

Install
-------

Just execute below code to install.

`wget https://raw.githubusercontent.com/sayem314/pirates-mediaserver/master/prowlarr/prowlarr-install.sh -O - -o /dev/null|bash`

Update
------

Just execute below code to update.

`wget https://raw.githubusercontent.com/sayem314/pirates-mediaserver/master/prowlarr/prowlarr-update.sh -O - -o /dev/null|bash`
